# UI inspiration & attribution

BeautyBook’s motion accents (hero mesh, area marquee, scroll reveals, brand shimmer)
are **original implementations** inspired by techniques popularized in:

| Source | License | How we use it |
|--------|---------|----------------|
| [Magic UI](https://github.com/magicuidesign/magicui) | MIT | Marquee / shimmer technique inspiration |
| [Animata](https://github.com/animata-design/animata) | MIT | Micro-reveal / hover motion ideas |
| [UI Layouts](https://github.com/ui-layouts/uilayouts) | Check repo | Animated section pacing |
| [Aceternity UI](https://ui.aceternity.com) | Check site terms | Marketing section composition ideas |
| [React Bits](https://github.com/DavidHDev/react-bits) | MIT + Commons Clause | Atmosphere/background *ideas only* — **no copied components** (Commons Clause forbids redistributing their components as a library) |
| [awesome-ui-resources](https://github.com/al-husayn/awesome-ui-resources) | Curated list | Discovery index for future blocks |

**Not adopted (too heavy / off-brand for booking UX):** react-three-fiber, drei, 3D portfolio templates.

We do not vend a third-party component pack; patterns are reimplemented to fit BeautyBook’s light theme and Manila salon marketplace.
